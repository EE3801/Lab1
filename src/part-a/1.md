# Part 2. Install the AWS Command Line Interface (CLI)

## 4. 

Although the AWS Management Console makes it easy to get started, we will need to use the command line interface to set up automation for our data pipelines. Follow the instructions here to install the AWS CLI (using the recommeded install script wherever possible):

<https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html>

> <p class="note"> Note 
>
>For Windows users, you can open the PowerShell app, copy the command from the webpage, and paste it into the command line.
>
>For Mac and Linux users, you can open the Terminal app, copy the command from the webpage, and paste it into the command line.

## 5.

Once the software has been installed, open a Terminal and type the following:

```bash
aws --version
```

This should return something like:

```bash
aws-cli/2.36.14 Python/3.14.6 Darwin/24.6.0 script-exe/arm64
```

If your version number is older, please upgrade to the latest version by following the instructions above.

You can set up aws with the following command:

```bash
aws configure
```

When prompted, use “ap-southeast-1” for region, "json" for output format, and enter the Key ID and Secret Key from the CSV above.

>
>```bash

>icacls.exe MyKeyPair.pem /reset
>
>icacls.exe MyKeyPair.pem /grant:r "$($env:USERNAME):(R)"
>
>icacls.exe MyKeyPair.pem /inheritance:r
>```
>
>The "|" symbol indicates that the output of the aws command will be sent to the Out-File command to create the "MyKeyPair.pem" file in the current directory. >```bash
>ls MyKeyPair.pem
>```

>
>```

# Part 3. Start an AWS EC2 Instance

## 7. 

Run the following to start up a Linux-based t3.micro EC2 instance:

```bash
aws ec2 run-instances --image-id resolve:ssm:/aws/service/ami-amazon-linux-latest/amzn2-ami-hvm-x86_64-gp2 --instance-type t3.micro --key-name MyKeyPair
```

You can learn about the different instance types (including t3.micro) at:

<https://aws.amazon.com/ec2/instance-types/>

## 8. 

Get the IP address of the EC2 instance using the following command:

```bash
aws ec2 describe-instances --filter "Name=instance-type,Values=t3.micro" --query "Reservations[].Instances[].PublicIpAddress"
```

# Part 4. Use your EC2 Instance

## 9. 

Copy a file to your EC2 instance using the secure copy command "scp" (replace "<ip_address>" below with the IP address you obtained above):

```bash
scp -i MyKeyPair.pem MyKeyPair.pem ec2-user@<ip_address>:~/
```

You will see a warning about the authenticity of the host, but you can go ahead and type "yes" to connect.

You can find out more about the scp syntax at:

<https://linuxize.com/post/how-to-use-scp-command-to-securely-transfer-files/>

If you encounter an error, follow the instructions in Step 11 before retrying this step.

Login to your EC2 instance:

```bash
ssh -i MyKeyPair.pem ec2-user@<ip_address> 
```

You should be able log right into your EC2 instance and your prompt should change to something like:

```bash
[ec2-user@ip-10-0-5-43 ~]$ 
```

List the files in the home directory of your EC2 instance:

```bash
[ec2-user@ip-10-0-5-43 ~]$ ls
```

You should see the file MyKeyPair.pem that you copied to your EC2 instance earlier in the file listing.

Logout from your EC2 instance:

```bash
[ec2-user@ip-10-0-5-43 ~]$ exit
```

You can also use the keyboard shortcut “Control-d” to logout.

# Part 5. Shut down your EC2 Instance

## 10. 

In order to terminate the EC2 instance, first get the Instance ID:

```bash
aws ec2 describe-instances --filter "Name=instance-type,Values=t3.micro" --query "Reservations[].Instances[].InstanceId"
```

Then run the following command to terminate the instance (replace "<ids_here>" with the Instance ID you obtained above):

```bash
aws ec2 terminate-instances --instance-ids <ids_here>
```

Verify that there are no EC2 instances running:

```bash
aws ec2 describe-instances --filter "Name=instance-type,Values=t3.micro" --query "Reservations[].Instances[].PublicIpAddress"
```
